# 结婚好日子 · 择日

给新人用的「合八字挑日子」网页工具。整页是「红帖封面 + 米色内页」的结构：封面整屏正红、囍字打底、撕纸边过渡到内页，择日法一段用红底反白做重音。输入新郎、新娘和双方父母的生辰，从未来半年到一年半里，
按通书择日的规则筛出三个适合办婚礼的日子，并给出当天的吉时、宜忌和逐条理由。

纯前端，无后端，无账号，打开即用。

## 怎么打开

- **直接双击 `index.html`**：双击就能用（Chrome / Edge / Safari 都可以），不需要装任何东西。
- 也可以起一个本地服务：`python -m http.server 8788`，然后访问 `http://127.0.0.1:8788/`。

部署到线上，把整个 `结婚好日子/` 目录丢到任意静态托管（对象存储、GitHub Pages、Vercel）即可。

## 使用流程

1. **其一 · 六个人的生辰**：生日用三个下拉选，**支持公历 / 农历切换**（很多长辈只记得农历，含闰月），选完立刻显示生肖与另一边历法的日期。时辰可以留「不确定」，只影响时柱；父母选填。
2. **选婚期范围**：起始年月 + 半年 / 一年 / 一年半；可选「优先周末」「避开农历七月」「避开农历六月」。
   - 婚礼要订酒店、发请帖，最早的一天不早于**一个月后**；选了已经过去的月份会自动顺延，并在结果上方说明。
3. **其二 · 三个日子**：首选 / 次选 / 备选，各带评分、等级、黄道值神、建除、宜忌、两个吉时和四条理由。
   - **统计条**：扫了多少天、划掉多少天、剩多少天、入选几个，下面一行写清划掉的原因。
   - **评分明细**：每张卡片可展开，从 62 分基础分开始，逐条列出加分扣分，加起来就是总分（满分 99）。
   - **格子图**：灰框是划掉的日子，浅红是可挑的日子，实红是选中的三天；点格子能看当天被划掉的具体原因。
   - **顺手定的三件事**：领证日（只排工作日、宜嫁娶、不冲新人）、回门日（婚后第三天，带冲煞）、请柬上的日期写法（一键复制）。
   - **婚事五件**：订婚、领证、婚礼、回门、入宅，一次排完，婚礼那天标红。每个都避开冲新人，领证只排工作日。\n   - **当天怎么走**：按当天吉时排出迎亲流程（化妆、出发、堵门、敬茶、仪式、开席、送客），吉时标红。\n   - **给长辈看的一页**：三条依据（没排八字 / 划掉了多少天 / 三个日子怎么比）+ 一段可直接复制发家庭群的话。\n   - **电子请柬**：填酒店和地址，生成 invite.html 链接，手机打开是红金请柬（日期、农历、地点、流程、回执）。\n   - **做成一张图**：生成 1080×1440 的竖版海报，右下角带二维码；扫码回到本页并带上你们的生日。\n   - **分享链接**：输入会编码进 `#q=`，发出去对方打开即还原并直接出结果；结果区顶部有四个快速动作（存图 / 复制链接 / 请柬 / 打印）。\n   - 可展开九个备选日子；可打印成两张 A4：第一张是择日帖（三个日子 + 六人八字 + 领证/回门 + 备婚时间表），第二张是迎亲流程，可直接给婚庆和车队。\n   - 看完想改条件，点「改条件，重新合」直接回到表单。
4. **其三 / 其四**：择日规则与常见问题，用来跟长辈解释，也用来让人相信这不只是随机数。

## 择日规则

引擎做的是**筛选与排序**，不做命理预测：不排大运、不看流年吉凶、不算财运子嗣。

### 一、硬性排除（不进入候选）

| 规则 | 说明 |
| --- | --- |
| 通书忌嫁娶 | 当日「忌」中出现「嫁娶」 |
| 通书未列嫁娶 | 当日「宜」中既无「嫁娶」也无「纳采 / 订盟」 |
| 月破 / 岁破 | 日支冲月建、冲流年支 |
| 四离四绝 | 春分、夏至、秋分、冬至前一日；立春、立夏、立秋、立冬前一日 |
| 杨公忌 | 农历正月十三、二月十一……十二月十九，共十三日 |
| 三娘煞 | 农历初三、初七、十三、十八、廿二、廿七 |
| 冲新人 | 日支冲新郎或新娘的**日支**、**生肖（年支）** |
| 冲父母 | 日支冲双方父母生肖（填了才检查） |
| 用户偏好 | 勾了「避开农历七月 / 六月」时排除该月 |

候选不足三个时按「杨公忌三娘煞 → 冲父母 → 冲新人生肖 → 通书宜忌」逐级放宽，界面上会明说放宽了什么。

### 二、加分

黄道值神（青龙、明堂、金匮、天德、玉堂、司命）+7；建除成日 +9、开日 +8、定日 +6、危 / 除日 +4、执日 +3；
天德贵人 +6、月德贵人 +5、天赦日 +5；二十八宿吉宿 +4；通书宜嫁娶 +7（宜纳采订盟 +4）；
与新人日支六合 +6、三合 +4；天喜 / 红鸾临日 +4；周末 +5。

### 三、扣分

黑道值神 −11；平日 −6、收日 −8、闭日 −10、建日 −5；宿凶 −4；月忌日（农历初五、十四、廿三）−3。

### 四、排序与成组

按总分排序（基础分 62，加减后封顶 99、保底 40），取分数最高的三天，要求彼此相隔 21 天以上、农历月不同；
不够再逐步放宽到 14 天、7 天。分数换算成「上上吉（≥95）/ 上吉（≥90）/ 吉（≥84）/ 中吉（≥76）/ 平」。

### 五、吉时

只取白天可用的时辰（卯时 05:00 到酉时 19:00），按「上午迎亲、午间开席」的常规流程加权，
再叠加时值神吉凶、时宜忌、是否冲新人日支与生肖，取前两个，标出适合做什么。

## 数据与隐私

所有计算在浏览器本地完成，没有后端、没有埋点、不写 cookie、不存 localStorage。
刷新页面即清空。

## 测试

```bash
node tests/engine.test.js      # 引擎：157 条断言
```

引擎测试覆盖：标准六人 / 只有新人 / 半年 / 一年半 / 闰月附近 / 避开农历七月 / 单长辈冲煞，
并断言「三个日子不冲新人、不冲父母、不是破日、通书不忌嫁娶、吉时不冲新人、严格口径下相隔 ≥21 天」，
另含历法对照用例（2024 立春 16:27、2025 春节、2027-05-15 甲午日）。

端到端测试在交付时另跑过一轮（91 项，全部通过），覆盖：加载无报错、零外部请求、表单校验与字段标红、
三个日子的完整性、统计条、格子图、复制、打印、备选展开、半年重算、避开七月、改条件重算、
过去月份顺延、19 个输入都有 label、axe 无 serious 违规、320–1440px 无横向溢出、断网 + file:// 可用。

历法内核另做过独立校验：604 个随机日期（1901–2099）的农历年月日与 `zhdate` 完全一致；
500 个随机日期的日柱与儒略日公式 `(JDN + 49) mod 60` 完全一致。

## 已知边界

- 时辰按北京时间排，未做真太阳时校正；子时按早子时（00:30）计。
- 历法范围 1900–2100；超出范围请换算法。
- 「冲父母生肖」按传统口径默认硬性排除，如果长辈不在意，可以在引擎里把 `ignoreParentChong` 打开。
- 宜忌来自 lunar-javascript 的通书神煞表，与港台版通书可能有个别差异。
